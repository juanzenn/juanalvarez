# Architecture decision records

One file per decision, `NNNN-kebab-case-title.md`, numbered in the order they
were accepted. A record is written once and not edited afterwards — if a later
decision changes course, add a new record and mark the old one superseded.

Traps and non-obvious behaviour belong in [CONTEXT.md](../../CONTEXT.md); these
records cover why a decision was made, not what will bite you.
